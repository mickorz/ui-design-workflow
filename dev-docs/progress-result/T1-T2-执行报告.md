## 关键设计决策

1. **design-session.md 采用「YAML frontmatter + Markdown 正文」**：frontmatter 承载全部机器可读状态（可被 Schema 校验），正文留给人类可读的会话备注，两全。
2. **confirmed 决策强制 source=user**：AI 建议（source=ai）一经用户确认即翻转为 user 来源，「AI 提议」的轨迹由 history 的 decision_proposed 事件保留。这条约束直接落实 DoD 的「不将 AI 建议错误标记为用户确认」。
3. **frozen 与阶段强一致**：Schema 层面约束 `frozen: true` 时 `stage` 必须为 `FROZEN`，把 DoD 的「未确认不能冻结」做成了机器可校验的不变量。
4. **每章状态标记统一**：design.md 的 13 个章节（含第 13 章决策记录）均带 `> 章节状态：` 标记，T4 完整性检查可统一解析。
5. **空白模板被 Schema 拒绝是有意设计**：project.name 为空的会话无意义，强制实例化时填写，避免生成无名设计。
