## 关键设计决策

1. **手动填充先行**：按执行顺序建议，先用 Dashboard 案例手动走完七阶段填充模板，再写 SKILL.md。验证发现 5 个问题（第 6/8 章划界、数据范围三问易漏、value 需词表、影响分析需映射表、冻结前 pending 必须清空），全部回写进 SKILL.md 与 references。
2. **规则分层**：不可违反的 8 条规则放 SKILL.md 本体；阶段方法论放 references 按需加载，SKILL.md 保持可一轮读完的粒度。
3. **影响分析做成映射表**：决策 category → 受影响章节的对应关系固化为表，S7 修改回路（案例中 D-009 → D-011）按表执行。
4. **委托决策有轨迹**：用户说「你定」时按推荐方案 confirmed，history 注明「用户委托 AI 决定」，保持审计能力。
